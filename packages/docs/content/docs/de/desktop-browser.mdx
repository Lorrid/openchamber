# Browser-Panel

Das Browser-Panel öffnet jede Seite direkt neben deinem Chat. Öffne es über die Globus-Schaltfläche in der Kopfzeile.

In der Desktop-App ist es ein echter Browser: Deine Logins bleiben erhalten, Hot Reload funktioniert, und die Entwicklerwerkzeuge sind einen Klick entfernt. In einem Browser-Tab zeigt das Panel eine Seite zwar an, kann aber nicht in sie hineinsehen — die Annotationswerkzeuge unten gibt es nur auf dem Desktop.

## Eine Seite annotieren

Drücke **Annotieren**, und über der Seite erscheint eine Leiste mit drei Werkzeugen:

- **Auswählen** — klicke Elemente an. Klicke mehrere, um gemeinsam über sie zu sprechen.
- **Bereich** — ziehe einen Rahmen um einen Ausschnitt.
- **Zeichnen** — skizziere frei über die Seite.

Sind Elemente ausgewählt, öffne **Stile**, um Textgröße und -stärke, Farben, Rahmen, Größe und Deckkraft zu ändern. Die Änderungen greifen auf der lebenden Seite, du siehst sie also sofort, und OpenChamber hält fest, was du von wo nach wo geändert hast.

Schreib dein Anliegen ins Kommentarfeld und drücke **Anhängen**. Deine Chat-Nachricht bekommt eine Karte mit allem Markierten, den gewünschten Stiländerungen und einem auf den Bereich zugeschnittenen Screenshot — du kannst also „dieser Button, etwas runder" sagen, statt zu beschreiben, wo er steht.

Nichts vom Ausprobierten bleibt zurück: Die Seite kehrt zu ihrem ursprünglichen Aussehen zurück, sobald die Annotation angehängt ist, und `Esc` bricht alles ab.

## Den Agenten steuern lassen

Der Agent kann das Browser-Panel selbst benutzen — eine Seite öffnen, lesen, was darauf steht, klicken, tippen und scrollen — um seine eigene Arbeit zu prüfen, statt dich darum zu bitten. Du siehst es im Panel passieren.

Beliebigen Code kann der Agent auf der Seite nicht ausführen. Der Browser behält deine echten Logins, deshalb bleibt er auf die genannten Aktionen beschränkt.

Das gehört zum OpenChamber-Agentenwerkzeug, das du unter **Einstellungen → Allgemein → OpenCode CLI** abschalten kannst.

## Entwicklerwerkzeuge

Drücke die Terminal-Schaltfläche in der Leiste, um Chromiums eigene Entwicklerwerkzeuge für die Seite zu öffnen — Konsole, Netzwerk, Elemente, alles Gewohnte.
