# 浏览器面板

浏览器面板会在聊天旁边打开任意页面。用应用标题栏的地球按钮打开它。

在桌面应用中，它是一个真正的浏览器：登录状态会保留，热重载可用，开发者工具一键即达。在浏览器标签页中，面板仍能显示页面，但无法查看其内部——下面的标注工具仅限桌面端。

## 为页面添加标注

按 **标注**，页面上方会出现一个包含三种工具的工具条：

- **选择** — 点击元素。可以选中多个，一起来讨论。
- **区域** — 拖拽出一个矩形框住某块区域。
- **绘制** — 在页面上自由手绘。

选中元素后，打开 **样式** 即可修改文字大小与字重、颜色、边框、尺寸和不透明度。改动会作用在实时页面上以便你查看，OpenChamber 会记录你把什么从什么值改成了什么。

在评论框里写下你的想法，然后按 **附加**。你的聊天消息会收到一张卡片，包含你标记的全部内容、你要求的样式改动，以及按该区域裁剪的截图——于是你可以说"这个按钮，再圆一点"，而不必描述它在哪里。

试用过的改动不会留下：标注一旦附加，页面就恢复原样式，按 `Esc` 可取消整个过程。

## 让智能体操作

智能体可以自己使用浏览器面板——打开页面、读取页面内容、点击、输入和滚动——从而自行检查工作成果，而不必来问你。你可以在面板中看到这个过程。

智能体无法在页面中执行任意代码。浏览器保留着你真实的登录状态，因此它只能执行上述操作。

这是 OpenChamber 智能体工具的一部分，可在**设置 → 通用 → OpenCode CLI** 中关闭。

## 开发者工具

按工具条上的终端按钮，即可打开 Chromium 自带的页面开发者工具——控制台、网络、元素，一应俱全。
